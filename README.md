# Chatbot – Trabalho Garantido FMU

### Sobre o projeto

Este projeto consiste no desenvolvimento de um chatbot informativo sobre o programa Trabalho Garantido da FMU, criado como parte de uma atividade acadêmica durante as aulas da faculdade.

A proposta é desenvolver uma ferramenta interativa capaz de responder dúvidas e fornecer informações sobre o programa Trabalho Garantido, facilitando o acesso dos alunos às informações de maneira simples, rápida e intuitiva.

### Objetivo

Aplicar na prática os conhecimentos adquiridos em sala de aula, utilizando a tecnologia de chatbot para criar uma solução que facilite a comunicação e o acesso às informações relacionadas ao programa Trabalho Garantido da FMU.
